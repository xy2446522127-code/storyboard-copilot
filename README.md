# 知瑶画布 / Storyboard Copilot

面向短剧、分镜和图像/视频生成工作流的本地桌面画布工具。

本仓库是从用户自有的 `5.5.0` Windows 发布版恢复并整理的开源项目。原始前端构建产物和随应用发布的即梦浏览器自动化模块均已保留；原生 Tauri 后端正按前端调用契约重建。

## 功能范围

- 无限画布项目管理、导入与导出
- 分镜图合并、切分与元数据读写
- OpenAI 兼容的图像、视频、对话与 TTS 接口
- 自定义模型 Provider 与模型列表获取
- FFmpeg 视频拼接、音频提取、字幕/水印裁剪与放大
- 即梦浏览器登录与生成工作流（需要用户自行登录）

## 安全原则

- 不包含 API Key、Cookie、会话 ID、项目数据库或日志。
- 所有云端 Provider 均要求用户在本机配置自己的凭据。
- 浏览器自动化不会导出或提交第三方账号 Cookie。

## 当前恢复状态

原界面资源和 Python 自动化模块已恢复。完整 Tauri 后端正在根据 `docs/COMMAND_CONTRACT.md` 实现；在发布前会进行静态凭据扫描、构建验证及本地功能回归。
